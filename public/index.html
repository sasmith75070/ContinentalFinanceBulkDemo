What this proves

  • One API call, thousands of sends. POST /v1/Messages accepts a to[] array of up to 10,000 recipients.
  • Personalization is native. Liquid variables ({{firstName}}, {{amountDue}}) resolve per-recipient with default filter fallbacks.
  • Per-recipient status. The Operations resource returns Delivered / Failed / Unaddressable counters that advance in real time.
  • Native scheduling, up to 7 days out. Pass schedule.sendAt in the same API call. Omit the timezone and Twilio auto-localizes each cardholder's send time — so an 8am–9pm ET window becomes 8am–9pm local for every cardholder, without per-zone logic in Continental Finance's scheduler.
  • Rich content, same API. Reference a Content Template by contentId (RCS card, MMS, WhatsApp), or pass inline RCS content. Add channels.priority — e.g. [{RCS: 0}, {SMS: 1}] — and Twilio delivers RCS where the cardholder's device supports it and automatically falls back to SMS everywhere else. One payload, richest supported format per cardholder.
Scene B

Cancel a scheduled SMS before it sends

If Continental Finance schedules a reminder and then the cardholder pays before it fires, they can cancel that SMS with one API call — as long as the message is still in scheduled status (up to about 15 minutes before the scheduled send time).

1
Schedule Jane's reminder (20 min out) Server calls POST /2010-04-01/Accounts/{Sid}/Messages.json with scheduleType=fixed, sendAt, and the Messaging Service SID. Twilio returns a MessageSid and status=scheduled.
→
2
Payment posts → cancel via Update Message Continental Finance's payment system POSTs to /webhooks/payment. Our server looks up Jane's MessageSid, then calls POST /Messages/{MessageSid}.json with Status=canceled. Twilio flips the status.
→
3
Twilio Console confirms Console → Monitor → Logs → Messaging → find the MessageSid. Status = canceled. No SMS was ever sent to the cardholder.
Cancellation window: Cancel only works while the message is in scheduled status. Twilio moves scheduled messages into queued roughly 15 minutes before sendAt. After that, cancellation returns error 30409. Design Continental Finance's schedule lead time with this window in mind.
